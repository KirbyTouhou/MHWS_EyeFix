# MHWS Eye Fix

《怪物猎人荒野》二次元 / MMD 移植 mod 的**眼球修复** Blender 插件。

一次处理三个互相纠缠的问题：

| 症状 | 原因 |
|---|---|
| 视线转向反向（该往左看却往右看） | 眼骨枢轴落在虹膜**前方** |
| 眼角几何乱动 | 上眼皮链吊在位置错误的 `*_Fake` 假骨下 |
| 转动看不见 / 幅度过小 | 枢轴离虹膜太近，或杠杆方向没瞄准 |

## 安装

下载 `MHWS_EyeFix.zip`，在 Blender 里 `编辑 > 首选项 > 插件 > 安装`，选中它（**不要解压**），然后勾选启用。

要求 Blender 4.3+。

## 使用

1. 打开 mod 的 `.blend`
2. 3D 视图按 `N` → **`MHWS`** 标签
3. 点 **诊断**（只读，不改任何东西）
4. 确认后点 **修复**
5. 重新导出（`fbxskel` 会在导出时重新生成）

诊断会列出：有哪些假骨、多少根面部骨与游戏原版不一致、哪些网格绑在眼骨上、每个眼球的枢轴在哪一侧、当前可见幅度是多少毫米。

> 「修正面部骨」会按游戏原版重排整棵面部骨架，**操作前请先备份**。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 眼球权重 | `0.5` | 眼球绑在眼骨上的权重，其余给 `Head`。越大转动越明显 |
| 杠杆瞄准正后方 | 开 | 保持杠杆长度不变，只把它转到虹膜正后方，水平分量全部变成看得见的左右位移；关掉则只翻转符号 |
| 杠杆倍率 | `1.0` | 在原始杠杆长度上乘系数。`1.0` = 与原模型一致，调大更明显但容易穿模 |
| 修正面部骨与假骨 | 开 | 删除 `*_Fake` 假骨，把面部骨架校正回游戏原版位置（修「眼角乱动」）|
| L_Eye / R_Eye 取原版位置 | 开 | 让导出的 `fbxskel` 里这两根眼骨与原版一致 |

幅度是按比例变的，先诊断看一眼「可见横移 XX mm」，不够再往上调。

没有这两个文件插件不会崩，只是会跳过「修正面部骨」，诊断里会提示。

> （Modding-Toolkit 自己的声明同样把 `assets/` 下的游戏文件排除在外）。
> 请自行从正版游戏或已安装的工具链中获取。

## 已知边界

- 只处理**面捕路径**上的眼球。识别眼球网格时认这几根骨：`L_EyeJ_LOD02` / `R_EyeJ_LOD02`（教程指明的眼球骨）、`L_Eye_Master` / `R_Eye_Master`（有些作者直接绑中枢骨）、`L_Eye` / `R_Eye`（MMD 带过来的身体眼骨）。修复时统一改绑到 `L_EyeJ_LOD02` / `R_EyeJ_LOD02`
- 眼白、眼皮、睫毛这些绑 `Head` + 眼皮骨的网格会被正确排除，不会误判成眼球
- 只针对《怪物猎人荒野》的面捕骨架，其他 RE Engine 游戏不适用

## 命令行

批量处理或回归测试用（`tools/cli_fix.py`）：

```bash
blender --factory-startup -b --python tools/cli_fix.py -- input.blend [output.blend] \
        [--weight 0.5] [--lever-scale 1.0] [--no-reaim] [--no-face] [--dry-run]
```

## 原理

绕竖直轴转 θ 时，虹膜中心的位移分成两个分量（`d = 虹膜中心 − 枢轴`）：

```
可见（左右滑动）   = 权重 × |d.y| × θ
看不见（前后进出） = 权重 × |d.x| × θ
```

**只有 `d.y` 那一份看得见**，所以枢轴要瞄准虹膜正后方 —— 同样的杠杆长度能多出 1.5~2 倍效果。完整推导和踩坑记录见 [`docs/eye-reversal-notes.md`](docs/eye-reversal-notes.md)。
