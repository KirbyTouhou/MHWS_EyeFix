# MHWS Eye Fix

怪物猎人荒野（Monster Hunter Wilds）二次元 / MMD 移植 mod 的**眼球修复** Blender 插件。

一次处理三个互相纠缠的问题：

| 症状 | 原因 |
|---|---|
| 视线转向反向（该往左看却往右看） | 眼骨枢轴落在虹膜**前方** |
| 眼角几何乱动 | 上眼皮链吊在位置错误的 `*_Fake` 假骨下 |
| 转动看不见 / 幅度过小 | 枢轴离虹膜太近，或杠杆方向没瞄准 |

已在两个来源不同的 mod 上验证，修复结果与手工逐步调试的版本逐位一致。

---

## 安装

**方式一（推荐）**：`编辑 > 首选项 > 插件 > 安装` → 选 `MHWS_EyeFix.zip` → 勾选启用。

**方式二**：把 `MHWS_EyeFix` 文件夹拷进
`%APPDATA%\Blender Foundation\Blender\<版本>\scripts\addons\`，重启后在插件列表里勾选。

要求 Blender 4.3+。

---

## 使用

1. 打开 mod 的 `.blend`
2. 3D 视图右侧 `N` 面板 → **`MHWS`** 标签
3. 点 **诊断**（只读，不改任何东西）。详情在 `窗口 > 切换系统控制台`
4. 确认问题后点 **修复**
5. 重新导出（`fbxskel` 会在导出时重新生成）

诊断会告诉你：有哪些假骨、多少根面部骨与游戏原版不一致、哪些网格绑在眼骨上、
每个眼球的枢轴在哪一侧、当前幅度是多少毫米。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| **眼球权重** | `0.5` | 眼球绑在眼骨上的权重，其余给 `Head`。越大转动越明显 |
| **杠杆瞄准正后方** | 开 | 保持杠杆**长度**不变，只把它转到虹膜正后方，水平分量全部变成看得见的左右位移。关掉则只翻转符号 |
| **杠杆倍率** | `1.0` | 在原始杠杆长度上乘系数。`1.0` = 与原模型一致；调大更明显但容易穿模 |
| **修正面部骨与假骨** | 开 | 删除 `*_Fake` 假骨，把整棵面部骨架校正回游戏原版位置（修「眼角乱动」）|
| **L_Eye / R_Eye 取原版位置** | 开 | 让导出的 `fbxskel` 里这两根眼骨与原版一致 |

幅度是按比例变大的，先诊断看一眼「可见横移 XX mm」，不够再往上调。

## 原理

绕竖直轴转 θ 时，虹膜中心的位移分成两个分量：

```
可见（左右滑动）   = 权重 × |d.y| × θ        d = 虹膜中心 − 枢轴
看不见（前后进出） = 权重 × |d.x| × θ
```

**只有 `d.y` 那一份是看得见的。** 所以：

- **枢轴要瞄准虹膜正后方** —— 把杠杆全部用在看得见的方向上，同样的长度能多出 1.5~2 倍效果
- **杠杆必须按「虹膜」量，不能按「虹膜+高光」的平均量** —— 高光通常比虹膜靠前零点几毫米，
  加权平均会把枢轴拉近，幅度凭空少掉 4~9%
- **枢轴 = 骨骼自己的世界位置**。改 rest 时必须保持「相对父级」不变，
  所以要移动就移动**整棵子树**；单独挪一根只会把几何弹开
- **高光权重必须与虹膜一致**，否则两者速度不同会脱节滑开
- 引擎按**骨骼名哈希**取骨、写的是**相对父级的 TRS**，所以插假骨改父级链没有用

更完整的推导和踩坑记录见 [`docs/eye-reversal-notes.md`](docs/eye-reversal-notes.md)。

## 已知边界

- 只处理**面捕路径**上的眼球。识别眼球网格时会认这几根骨：
  `L_EyeJ_LOD02` / `R_EyeJ_LOD02`（教程指明的眼球骨）、
  `L_Eye_Master` / `R_Eye_Master`（有些作者直接绑中枢骨）、
  `L_Eye` / `R_Eye`（MMD 带过来的身体眼骨）。
  修复时统一改绑到 `L_EyeJ_LOD02` / `R_EyeJ_LOD02`
- 眼白、眼皮、睫毛这些绑 `Head` + 眼皮骨的网格会被正确排除，不会误判成眼球
- **「修正面部骨」会按游戏原版重排整棵面部骨架，操作前请备份**
- 只针对怪物猎人荒野的面捕骨架，其他 RE Engine 游戏不适用

## 目录结构

```
MHWS_EyeFix/
    __init__.py                  插件本体
    README.md
    LICENSE                      GPL-3.0-or-later
    refs/                        参照物放这里（仓库里只有说明）
    tools/
        cli_fix.py               命令行版，批处理/回归用
        deploy.py                开发用：把本文件夹同步到 Blender 插件目录
        package.py               开发用：打 dist/MHWS_EyeFix.zip
    docs/
        eye-reversal-notes.md    完整推导与踩坑记录
```

命令行用法：

```bash
blender --factory-startup -b --python tools/cli_fix.py -- input.blend [output.blend] \
        [--weight 0.5] [--lever-scale 1.0] [--no-reaim] [--no-face] [--dry-run]
```
