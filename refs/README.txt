这个目录用来放「游戏原版参照物」。

插件需要两个文件才能做面部骨比对：

    MHWilds_Female.fbx            游戏原版猎人骨架（含完整面部骨，573 根）
    ch03_000_9000.fbxskel.7       游戏原版身体骨架（224 根）

怎么放进来
----------
如果这台机器装了 Modder_Batch_Tool 或 Modding-Toolkit：

    打开 Blender -> N 面板 -> MHWS Eyefix -> 参照物 -> 「把参照物复制到插件目录」

插件会自动找到并复制过来。之后即使换一台没装工具包的电脑，
只要带着整个 MHWS_EyeFix 文件夹，插件依然能用。


关于版权
--------
上面那两个文件是卡普空（CAPCOM）的游戏资产，不是本插件的一部分，
也不在插件的授权范围内（Modding-Toolkit 自己的授权声明里同样把
assets/ 下的游戏文件排除在外）。

所以：

  * 请只在自己使用的机器之间拷贝
  * 不要把带 refs/ 内容的整个文件夹公开分发
  * 要分享给别人的话，分享不带 refs/ 的插件包，
    让对方自己从自己的游戏/工具包里取

没有这两个文件时插件不会崩，只是「修正面部骨」这一项会被跳过，
诊断里也会明确提示。
